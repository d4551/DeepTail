# Why `.oxlintrc.json` turns three rules off, and only where

Each entry is scoped to the one file that needs it. None is a repo-wide relaxation.

- **`no-underscore-dangle` allowlist** — `__DSH_BOOT_READY__`, `__DSH_TRANSPORT__`,
  `__DSH_BOOT__` and `__ModuleLoader__` are the harness's own page-boot protocol
  globals. Their names are the contract; renaming them breaks the handshake.

- **`unicorn/require-module-specifiers` in `packages/host-fleet/src/index.ts`** —
  `import type {} from '…'` is the harness idiom for pulling a package's
  `declare module` augmentations into scope. The empty brace list is what keeps
  it type-only; removing it makes the line a runtime side-effect import and
  changes what the emitted JavaScript does.

- **`no-await-in-loop` in `apps/deeptail/src/injections.ts`** — the boot table is
  ordered, and a `global` row must land before the scripts that read it.
  Awaiting each row is the contract; `Promise.all` would race the rows and break
  the handshake.

- **`unicorn/prefer-add-event-listener` in `apps/deeptail/src/transport.ts`** —
  Tauri's `Channel` is not an `EventTarget`. Assigning `onmessage` is the only
  API it exposes.
